## 🔴 ĐANG DANG DỞ — BUG MÀN ĐEN (chưa fix — ưu tiên #1)

**Triệu chứng (user xác nhận qua 2 ảnh):** chạy `npm run dev` → cửa sổ "Danh Script" mở lên nhưng **đen thui**, không render gì. Vào 1 dự án cũng đen. **Các step trong wizard cũng đen.** Nguyên văn user: *"mở xong bắn xem dự án bị màn đen, ở các step nãy cũng bị"*.

**Đã loại trừ:**
- **Main process log SẠCH** — build main + preload + renderer đều `✓`, dev server chạy `http://localhost:5173`, "start electron app..." bình thường. Không có lỗi khởi động ở main.
- **KHÔNG phải do commit `cf286f8`** — màn đen hiện ngay Dashboard (chưa mount `WizardView`). 3/4 file trong commit là main process (không crash renderer), 1 file là `WizardView.tsx` chỉ mount khi vào dự án. Màn đen ở Dashboard ⇒ nằm ngoài phạm vi commit.
- **Đã restart sạch** (kill electron + node rồi `npm run dev` lại) → VẪN đen.

**Chưa có chứng cứ gốc:** chưa đọc được **console của renderer**. Browser sandbox / preview tool / curl KHÔNG với tới `localhost:5173` bên trong Electron (trả `chrome-error`, HTTP 000). → Màn đen = renderer JS crash, React không mount được `#root`, nhưng chưa thấy stack trace.

### Việc cần làm ĐẦU TIÊN ở chat mới (theo systematic-debugging Phase 1 — CẤM fix mù)
1. **Nhờ user mở DevTools trong chính cửa sổ Electron:** nhấn **Ctrl+Shift+I** (hoặc menu View → Toggle Developer Tools) → tab **Console** → chụp dòng lỗi **màu đỏ** đầu tiên. Đây là chứng cứ gốc còn thiếu.
2. Nếu không mở được DevTools: thêm tạm `window.onerror`/`window.addEventListener('error')` trong `src/renderer/src/main.tsx` ghi lỗi ra file, HOẶC bọc `<App/>` bằng một `ErrorBoundary` render lỗi ra màn hình. Chạy lại, đọc lỗi, rồi mới sửa.
3. Chỉ sau khi có stack trace mới xác định root cause và fix.
